 
# Architecture

## Source Structure

- `assets/` - Stores static assets such as images, icons, and fonts.
- `components/` - Contains reusable UI components.
- `hooks/` - Contains reusable custom React hooks.
- `utils/` - Contains reusable helper functions.
- `data/` - Stores static data used throughout the application.
- `types/` - Contains TypeScript type definitions.

## Adding New Files

- **New Page:** Add it inside `src/`. If the project introduces a `pages/` folder, place new page components there.
- **New Hook:** Add it inside `src/hooks/`.
