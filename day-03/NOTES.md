Parameter و Argument

الـ Parameter هو المتغير اللي بكتبه في تعريف الـ function.

الـ Argument هي القيمة الفعلية اللي ببعتها للـ function وقت استدعائها.

<!-- ================================================================================================================= -->

Function Declaration: بستخدمها لما أحتاج أعمل function عادية باسم، وممكن أستدعيها قبل ما أكتب تعريفها.

Function Expression: بستخدمها لما أحتاج أخزن function جوه variable.

Arrow Function: بستخدمها لما أحتاج أكتب function بطريقة أقصر، خصوصًا مع الـ callbacks والـ functions البسيطة.

<!-- ================================================================================================================= -->

الـ return بترجع قيمة من الـ function عشان أقدر أستخدمها بعد كده، لكن console.log وظيفتها بس إنها تعرض القيمة في الـ console.

<!-- ================================================================================================================= -->

الـ Guard Clause بتفحص الحالة الغلط أو الخاصة في بداية الـ function، ولو حصلت بعمل return فورًا، وده بيخليني أتجنب الـ nested if / else الكتير.

Global Scope: المتغير اللي بيتعمل هنا ممكن أستخدمه من أماكن مختلفة، طالما مفيش variable أقرب بنفس الاسم.

Function Scope: المتغير اللي بيتعمل جوه function أقدر أستخدمه جوه الـ function دي فقط.

Block Scope: المتغير اللي بيتعمل بـ let أو const جوه {} أقدر أستخدمه جوه الـ block دي فقط.

<!-- ================================================================================================================= -->

الـ Scope Chain هي الطريقة اللي JavaScript بتدور بيها على variable: تبدأ من الـ scope الحالي، ولو ملقتهوش تطلع للـ parent scope، وبعدها للـ scope اللي فوقه لحد الـ Global Scope.

<!-- ================================================================================================================= -->

Function: تعريف الـ function declaration بيكون متاح حتى قبل مكان كتابته في الكود.

var: الـ declaration بتاعه بيتم رفعه، وبيبدأ بقيمة undefined.

let: الـ declaration بتاعه بيتم رفعه، لكن مينفعش أستخدمه قبل سطر تعريفه.
وبيديني RefrenceError

const: نفس let، بيتم رفع الـ declaration لكن مينفعش أستخدمه قبل سطر تعريفه.
وبيديني RefrenceError

 <!-- ================================================================================================================= -->

  <!-- ================================================================================================================= -->

الـ function تقدر تفتكر وتستخدم الـ variables الموجودة في المكان اللي اتعملت فيه حتى بعد ما المكان ده خلص تنفيذه
